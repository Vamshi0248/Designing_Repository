# Design System

A comprehensive design system with reusable UI components including buttons, grid, typography, colors, and spacing.

## Components

- **Buttons** - Various button styles and states
- **Grid System** - Responsive grid layout
- **Typography** - Text styles and hierarchy
- **Colors** - Color palette and utilities
- **Spacing** - Consistent spacing scale

## Getting Started

Explore the components in the `components` directory to see implementation details and usage examples.

## Features

- Responsive design
- Accessible components
- Consistent styling
- Easy to customize
